# 《阿瓦隆》服务器权威状态机

```text
lobby → secretReveal → teamProposal → teamVote
                              ↑          ├─ 否决(<5) → 下一队长
                              │          ├─ 否决(=5) → ended
                              │          └─ 通过 → questAction
                              │                         ↓
                              │                  questResolution
                              │                    ├─ 三败 → ended
                              │                    ├─ 三胜 → assassination → ended
                              │                    ├─ 仙女触发 → ladyInspect ─┐
                              └────────────────────┴─────────────────────────┘
```

服务器保存角色、阵营、角色知识、队长、任务序号、提案次数、队伍、秘密组队票、秘密任务牌、湖中仙女历史、截止时间、结算、公共日志和演出事件。浏览器只提交选队、投票、任务牌、查验目标和刺杀目标等意图。

组队草稿在确认前仅存在队长浏览器中，绑定房间、对局、任务、提案序号和行动者；普通视图刷新、在线状态变化与旁观加入不得清空。服务端仍在确认时重新验证成员数量、身份和当前状态版本。
