# game22《阿瓦隆》体验外壳

## 世界观与关键词

玩家身处卡美洛圣殿的圆桌议事厅，以骑士纹章立誓远征，而莫德雷德的爪牙潜伏在誓约之中。

关键词：**卡美洛圣殿、誓约与背叛、圣杯远征**。

## 核心桌面

- 五段远征路径是整局进度主轴，成功节点点亮金色圣杯，失败节点出现暗红裂纹。
- 宽屏下骑士纹章围绕石质圆桌，中央是队长的誓约环和当前提案。
- 五次否决表现为王冠封印逐步破裂。
- 私人身份是一张只向本人展开的密封纹章卡。
- 规则、王国编年史和旁观席分别收纳为圣殿卷宗，不复制固定侧栏模板。

## 演出语言

- 选人：队长向目标延伸金色誓约线。
- 组队投票：玩家放下密封蜡印，结算时同时翻面。
- 任务：队员把任务牌投入圣杯，匿名混洗后由圣杯呈现金色或裂纹。
- 湖中仙女：银蓝湖光连接持有者和目标，但结果仅进入持有者视图。
- 刺杀：暗红匕首轨迹指向目标，随后全员纹章翻转揭晓。

## 响应式构图

- 宽屏：远征路径在上，圆桌与纹章为中心，操作誓约书位于桌沿。
- 手机：远征路径压缩置顶，玩家改为双列/单列纹章名单，不继承圆桌绝对坐标；底部吸附有限高度操作坞。
- 旁观者取消操作坞吸附，只显示公共进度与状态摘要。

隐藏标题后，应仍可通过五段远征路径、石质誓约圆桌、骑士纹章、蜡印投票和圣杯任务动画识别本游戏。
