# game23 · 只言片语

服务端权威的 3～8 人图像联想与秘密投票游戏。

- 启动：`node game23/signal-server.js`
- 默认端口：`8809`
- 数据库：`GAME23_DB_PATH`，默认 `game23/.data/game23.sqlite`
- 规则：`RULES.md`
- 状态机：`STATE_MACHINE.md`
- 视觉：`VISUAL_DESIGN.md`
- 卡牌素材：`assets/cards/` 共 100 张；当前正式牌组使用 `card_00001.jpg`～`card_00084.jpg`，其余16张作为扩展储备。
- 素材来源与授权记录：`assets/cards/SOURCE.md`
